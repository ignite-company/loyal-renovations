# Loyal Renovations

Responsive, static, single-page renovation company website.

## Deployment

- Source repository: `ignite-company/loyal-renovations`
- Production URL: https://loyal-renovations.vercel.app
- Vercel project: `loyal-renovations`
- No build step or dependencies required; deploys `index.html` as a static site.

## Brand

Deep navy `#101d2c`, warm gold `#c39a59`, light stone `#f3f0ea`.

The supplied logo is loaded from a hosted image URL. The images in the design inspiration section are explicitly **not** represented as completed Loyal Renovations work.

## Before accepting live inquiries

The project forms currently open the visitor's email application with a pre-addressed message to `asher.igniteco@gmail.com`. They **do not send or store submissions automatically**. Replace with a verified server-side email/CRM integration before paid advertising or a public launch where immediate lead delivery is required. Confirm business email, service area, licensing/insurance details, actual offered services and proof photography with the construction partner before publishing claims.

## Website structure

Single-page anchor navigation: home, story, services, inspiration, process, FAQs, and contact. Mobile navigation and quote modals are implemented in `index.html` with no JavaScript dependencies.

For SEO, robots.txt and sitemap.xml use the Vercel URL; update these when a custom domain is connected.
